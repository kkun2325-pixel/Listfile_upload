# 05 アップロード履歴ページ

**ルート:** `/dashboard/history`  
**ファイル:** `app/dashboard/history/page.tsx`  
**API:** `GET /api/uploads` / `GET /api/history`

---

## 概要

過去にアップロードしたCSVファイルの一覧を表示するページ。  
アップロード日時・ファイル名・件数・ステータスを一覧表示。  
各行から詳細ページへ遷移できる。
