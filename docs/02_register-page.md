# 02 ユーザー登録ページ

**ルート:** `/register`  
**ファイル:** `app/register/page.tsx`  
**API:** `POST /api/auth/register`

---

## 概要

新規ユーザーがアカウントを作成するページ。  
名前・メールアドレス・パスワードを入力して登録。  
登録後はログインページへリダイレクト。
